## Status

Hemiciclo is in planning, and no application code exists yet. The route to the
first version is charted as a map of decision tickets on this repository's
issue tracker under the
[`wayfinder:map`](https://github.com/lutzseverino/hemiciclo/issues?q=label%3Awayfinder%3Amap)
label.
